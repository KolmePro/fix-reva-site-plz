# FIX REVA SITE PLZ!

Расширение для игроков Revelation Online, которое делает работу с [revonline.ru](https://revonline.ru) и [market.vkplay.ru](https://market.vkplay.ru) быстрее и удобнее.

## ✨ Возможности

### На revonline.ru

- Массовая активация PIN-кодов, включая списки с заголовками групп наград.
- Быстрая активация PIN-кодов через API без всплывающих окон сайта, с прогрессом, остановкой и копированием оставшихся кодов для продолжения после обновления страницы.
- Автоматическое открытие карт Куроми с выбором желаемых призов.
- Автоматическая отправка предметов персонажу.
- Автопрокрутка колеса Атума с турбо-режимом и списком полученных наград.
- Массовое открытие одинаковых сундуков с выбранной наградой.

### На market.vkplay.ru

- Быстрое получение всех доступных PIN-кодов через API с учётом поиска и фильтров, без всплывающих окон сайта.
- Остановка получения PIN-кодов в любой момент.
- Копирование неактивированных PIN-кодов текущей игры с группировкой по наградам и выбором страниц: все, указанное количество или автоматический просмотр.
- Быстрое открытие всех оставшихся сундуков выбранного типа без анимации, со списком наград и кнопкой остановки.

Добавленные расширением элементы выделены фиолетовым цветом, поэтому их легко отличить от стандартного интерфейса сайтов.
