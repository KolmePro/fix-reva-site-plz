# FIX REVA SITE PLZ!

Расширение для игроков Revelation Online, которое делает работу с [revonline.ru](https://revonline.ru) и [market.vkplay.ru](https://market.vkplay.ru) быстрее и удобнее.

## ✨ Возможности

### На revonline.ru

- Массовая активация PIN-кодов.
- Автоматическое открытие карт Куроми с выбором желаемых призов.
- Автоматическая отправка предметов персонажу.

### На market.vkplay.ru

- Открытие всех PIN-кодов одним нажатием.
- Быстрое копирование доступных PIN-кодов.

Добавленные расширением элементы выделены фиолетовым цветом, поэтому их легко отличить от стандартного интерфейса сайтов.

## Установка из исходников

1. Скачайте или клонируйте репозиторий.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку с файлами расширения.

После обновления файлов нажмите кнопку обновления на карточке расширения и перезагрузите открытые страницы поддерживаемых сайтов.

## Проверка изменений

Для проверки синтаксиса JavaScript-файлов выполните:

```powershell
node --check revonline-pins.js
node --check revonline-collection.js
node --check revonline-cart.js
node --check vkplay-pins.js
```

После этого загрузите расширение в Chrome и проверьте изменённую функцию на соответствующей странице.

## Публикация новой версии

Репозиторий автоматически собирает и отправляет отмеченные тегами версии в Chrome Web Store. После проверки Google новая версия публикуется автоматически.

### Однократная настройка

1. Включите Chrome Web Store API в проекте Google Cloud.
2. Создайте сервисный аккаунт и добавьте его адрес в раздел Account в Chrome Web Store Developer Dashboard.
3. Разрешите сервисному аккаунту выпускать собственные OAuth-токены, назначив ему роль Service Account Token Creator для самого себя.
4. Создайте JSON-ключ сервисного аккаунта.
5. Добавьте в GitHub Actions следующие настройки:
   - секрет `CWS_SERVICE_ACCOUNT_JSON` с минифицированным содержимым JSON-ключа;
   - переменную `CWS_SERVICE_ACCOUNT_EMAIL` с адресом сервисного аккаунта;
   - переменную `CWS_PUBLISHER_ID` со значением Publisher ID из Developer Dashboard.

Ключ сервисного аккаунта нельзя добавлять в Git или передавать другим людям.

Для проверки авторизации без загрузки пакета вручную запустите workflow **Chrome Web Store**, включив параметр `verify_api`.

### Выпуск версии

Сначала обновите поле `version` в `manifest.json` и закоммитьте изменения. Затем создайте и отправьте тег с той же версией:

```powershell
git tag v1.6
git push origin v1.6
```

Если версия тега отличается от версии в manifest, публикация будет остановлена. Готовый ZIP-архив также сохраняется среди артефактов запуска GitHub Actions на 30 дней.
