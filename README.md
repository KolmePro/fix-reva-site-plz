# FIX REVA SITE PLZ!

Расширение для игроков Revelation Online, которое делает работу с [revonline.ru](https://revonline.ru) и [market.vkplay.ru](https://market.vkplay.ru) быстрее и удобнее.

## ✨ Возможности

### На revonline.ru

- Массовая активация PIN-кодов.
- Автоматическое открытие карт Куроми с выбором желаемых призов.
- Автоматическая отправка предметов персонажу.

### На market.vkplay.ru

- Открытие всех PIN-кодов одним нажатием.
- Быстрое копирование доступных PIN-кодов.

Добавленные расширением элементы выделены фиолетовым цветом, поэтому их легко отличить от стандартного интерфейса сайтов.

## Установка из исходников

1. Скачайте или клонируйте репозиторий.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку с файлами расширения.

После обновления файлов нажмите кнопку обновления на карточке расширения и перезагрузите открытые страницы поддерживаемых сайтов.

## Проверка изменений

Для проверки синтаксиса JavaScript-файлов выполните:

```powershell
node --check revonline-pins.js
node --check revonline-collection.js
node --check revonline-cart.js
node --check vkplay-pins.js
```

После этого загрузите расширение в Chrome и проверьте изменённую функцию на соответствующей странице.

🚨 Расширение работает только на поддерживаемых страницах revonline.ru и market.vkplay.ru.

**FIX REVA SITE PLZ!** — неофициальное пользовательское дополнение, не связанное с администрацией указанных сайтов.
